## 论文与研究

### 已录用 · Accepted

- **P4casting：数据与控制平面协同的双时间尺度在线流量预测**  
  IEEE HPCC 2026（CCF-C），第二作者、通讯作者。通过数据平面流管理与控制平面深度学习协同，实现在线流量预测与突发检测。[项目仓库](https://github.com/f1ybaozii/p4casting)
- **AURORA：基于数据平面线速预测的自适应负载均衡机制**  
  IEEE ISCC 2026（CCF-C），第三作者。在 P4 数据平面中结合流量预测、动态权重与无状态连接一致性，实现线速自适应负载均衡。
- **AdaTable：容量漂移下鲁棒 VNF 自动扩缩容的学习式校准**  
  ICIC 2026，第三作者。通过快慢双平面容量表校准，平衡服务能力漂移下的扩缩容成本与 SLA。[论文](https://link.springer.com/chapter/10.1007/978-981-92-3441-7_30)

### 在投 · Under Review

- **RecPipe：面向数据平面流量分类的 RNN 模型自上而下蒸馏**  
  USENIX NSDI 2027（CCF-A，在投），第一作者。将按流训练的 RNN 蒸馏为硬件预算内的有限状态表示，支持可编程交换机上的流量分类。
- **Granulaxis：面向可编程网络攻击缓解的证据驱动粒度细化**  
  IEEE INFOCOM 2027（CCF-A，在投），第五作者。通过交换机、DPU 与控制器协同采集证据，在共享规则预算下选择攻击缓解粒度。
