P4casting: Data-Control Plane Synergistic Real-time Short-term Network Traffic Prediction 2026.03 – 2026.05
IEEE SMC (CCF-C, Under Review) · Second Author | Corresponding Author

A data-control plane co-designed system that leverages Count-Min Sketch for line-rate feature extraction and Transformer for online inference, achieving real-time encrypted traffic prediction on programmable switches.

▼ Details

Background & Motivation: Existing approaches for encrypted network traffic short-term prediction suffer from low accuracy and high latency. Proposes P4casting, an end-to-end online traffic prediction system with data-control plane synergy.

Design: On the data plane, implements a P4 pipeline including packet parsing, feature computation, line-rate extraction of flow-level stateful features (Count-Min Sketch, bucket aggregation) and packet-level stateless features. On the control plane, deploys a Transformer-based online prediction model with closed-loop feature reporting and model inference via P4Runtime. Designs online register read/write logic tailored to data plane hardware constraints.

Results: Prototype deployed on Intel Tofino switches (SONiC) and Linux servers. Evaluated on MAWI real-world traces — outperforms EWMA, LSTM, and two Transformer variants with end-to-end average latency of 3.15ms. Low hardware overhead (SRAM 18.72%, TCAM 2.08%).

My Contributions:

  • Independently designed the approach and experiments. Wrote server/control-plane Python code and 1500 lines of data-plane P4 code; conducted traffic prediction experiments on MAWI 2025 traces.
  • Authored the full manuscript (second author / corresponding author) submitted to IEEE SMC. A patent is in preparation.

AURORA: An Adaptive Load Balancing Mechanism with Line-rate Traffic Prediction in Data Plane 2025.06 – 2025.07
IEEE ISCC (CCF-C, Accepted) · Third Author

A fully in-data-plane load balancing mechanism that uses integer-approximated Holt smoothing for burst-aware server weight adaptation without control plane intervention.

▼ Details

Background & Motivation: Addresses load balancing lag and server overload under short-term burst traffic in data centers. Proposes AURORA, a prediction-driven load balancing mechanism on P4 programmable data plane that achieves line-rate adaptive scheduling without control plane intervention.

Design: Implements integer-approximated Holt double-exponential smoothing entirely in the data plane to predict next-window connection counts. Designs traffic scaling coefficients for dynamic server weight adjustment with probabilistic interval mapping for fair distribution. Embeds server IDs in TCP timestamps to ensure connection consistency in a stateless data plane, avoiding TCAM/SRAM flow table overflow and supporting massive concurrent connections.

Results: Prototype deployed on Intel Tofino switches with single-leaf topology. Validated with Poisson-arrival and Pareto-distributed traffic (10×/20× burst windows). Results: CPU utilization imbalance reduced by 84.7%, flow completion time reduced by 15.1%, TCP abnormal termination rate only 1.6%. Low hardware overhead (SRAM 15.6%, TCAM 25%).

My Contributions:

  • Contributed to the Holt double-exponential traffic prediction model and server weight design.
  • Authored the main body of the paper as student second author, including background, motivation, related work, system overview, and detailed design; organized related work on load balancing.

AURORA：一种数据平面线速流量预测的自适应负载均衡机制 2025.06 – 2025.07
IEEE ISCC (CCF-C, 录用) · 三作

在数据平面内纯粹实现的预测驱动负载均衡机制，无需控制平面参与即可自适应应对突发流量。

▼ 项目内容

背景与动机：针对数据中心短时突发流量下负载均衡响应滞后、服务器过载的问题，提出基于P4可编程数据平面的预测驱动负载均衡机制AURORA，无需控制面干预即可实现线速自适应调度。

主要设计：在数据平面内整数近似实现霍尔特双参数时序预测模型，实时预测下一时间窗口的连接数，并设计流量缩放系数动态调整服务器权重，结合概率区间映射完成公平分发。通过TCP时间戳字段嵌入服务器标识，在无状态数据平面中保证连接一致性，避免TCAM/SRAM流表溢出，支持大规模并发连接。

实验结果：在Intel Tofino可编程交换机及单层树拓扑上完成原型部署，使用泊松到达和帕累托分布流量（10倍/20倍突发窗口）进行验证。结果表明：CPU利用率不平衡度降低84.7%，流完成时间降低15.1%，TCP异常中断率仅1.6%，硬件资源开销低（SRAM 15.6%、TCAM 25%）。

工作内容：

  • 参与霍尔特双参数法相关的流量预测模型和服务器权重的设计，作为学生二作撰写论文主体内容，包括论文背景、动机与相关工作，设计总述和详细设计，对负载均衡的相关工作进行整理。
